A make.fun entry for "Make the AI Judge Laugh: Developer Excuses" — one funny single-line excuse a developer gives when code breaks in production, under 200 characters.

**The entry:**

> It passed all 400 tests. Production was test 401.

## Run

```sh
python3 main.py
```

Writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads it back and verifies it byte-for-byte. Standard library only.
